# 👋 Hi, I'm Rojarani Daasari

### AWS DevOps Engineer | Cloud Infrastructure | CI/CD | Docker | Kubernetes | Terraform

I work on building, automating, and deploying cloud-native applications using AWS and modern DevOps practices.
